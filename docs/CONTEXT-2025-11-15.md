```clojure
(ns mcp-nrepl-proxy.calculator
  (:require [sci.core :as sci]))

;; 1. Define math-fns map (50+ functions)
(def math-fns
  {;; Arithmetic: + - * / mod quot rem inc dec
   ;; Powers: pow sqrt cbrt exp
   ;; Logarithms: ln log10 log2 logb
   ;; Trigonometry: sin cos tan asin acos atan atan2 sinh cosh tanh sind cosd tand
   ;; Rounding: abs floor ceil round sign trunc
   ;; Constants: pi e tau phi
   ;; Comparisons: < > <= >= = not=
   ;; Vectors: sum product vmin vmax count
   ;; Statistics: mean median variance stdev
   ;; Linear algebra: dot norm cross
   ...})

;; 2. Create SCI context (simplified - no security paranoia)
(def sci-ctx
  (sci/init
    {:bindings math-fns
     :allow '[let if when cond -> ->> as-> fn defn]
     :realize-max 10000}))

;; 3. Implement timeout-protected calculate function
(defn calculate
  "Evaluate mathematical expression with timeout protection.
   Returns {:result ... :type ... :expr ...} or {:error ... :type ... :expr ...}"
  [expr-string]
  (let [timeout-ms 5000
        result-promise (promise)]
    (future
      (try
        (deliver result-promise
                 (let [result (sci/eval-string* sci-ctx expr-string)]
                   {:result result
                    :type (str (type result))
                    :expr expr-string}))
        (catch Exception e
          (deliver result-promise
                   {:error (.getMessage e)
                    :expr expr-string
                    :type "error"}))))
    (deref result-promise timeout-ms
           {:error "Calculation timeout (>5s)"
            :type "timeout"
            :expr expr-string})))
```

## 💡 KEY DECISIONS & CONTEXT

### Security: Non-Issue
- `nrepl-eval` already allows arbitrary code execution
- `calculate` doesn't add attack surface
- SCI sandbox is for accident prevention, not security
- **Implication**: Simplified configuration, no security paranoia

### Timeout: Critical
- MCP interface is **synchronous**
- Hanging calculation freezes entire session
- 5-second timeout with promise/future pattern
- Return `{:error "..." :type "timeout"}` on timeout
- **This is non-negotiable**

### Tool Selection Psychology
- Dedicated tools reduce cognitive friction for LLMs
- "calculate" tool name → instant match for math tasks
- Focused description → high confidence
- Pre-loaded functions → no uncertainty
- **User hypothesis validated**: More inviting than overloading nrepl-eval

### Standalone SCI Implementation
- **Correct approach** vs wrapper around nrepl-eval
- Faster (no network round-trip)
- Simpler (no connection management)
- Isolated (doesn't pollute nREPL session)
- Precedent exists (local-eval already uses SCI)

### Testing: Dual Approach
1. **Traditional RPC testing**: Unit + integration tests
2. **AI-driven scenarios**: Natural language test cases (30 scenarios in calculator-ai-test-scenarios.md)
3. Benefits: Tests both technical correctness AND LLM usability
